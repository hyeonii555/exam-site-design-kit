# 시험 준비 사이트 디자인 키트

HyDS3 시험 준비 사이트를 **새로** 만들 때 쓰는 디자인 키트예요. 어두운 애플 앱 느낌(검정 바탕, 파랑 한 가지, 미끄러지는 탭, 한 화면에 들어가는 배치)의 화면 견본과 CSS·JS가 들어 있어요.
사이트는 두 탭이에요: **모의시험**(회차 고르기 → 문제 풀이 → 채점), **시험 대비**(시험 문제를 붙여 넣으면 소문항마다 MASTER 코드와 기출 풀이 원본을 보여 줌).

예시 페이지의 내용(카페 판매 데이터, 코드)은 모두 지어낸 것이에요.

## 받는 법

1. 깃허브 저장소에서 'Code' → 'Download ZIP'으로 받아요(로그인 필요 없음).
2. 압축을 풀고 안의 `design-kit` 폴더를 새 사이트를 만들 곳에 둬요.
3. `design-kit/pages/index.html`을 브라우저로 열면 예시 화면을 볼 수 있어요. 인터넷 없이 열리고, 오른쪽 위 '보기'에서 어둡게·밝게와 글자 크기를 바꿀 수 있어요.

## 사내 클로드 코드에게 할 말

`design-kit` 폴더와 회사 자료 폴더가 같이 있는 곳에서 클로드 코드를 열고:

> design-kit/CLAUDE.md를 먼저 끝까지 읽고 규칙을 지켜 줘. 그다음 design-kit/guide/00-start.md부터 한 단계씩 해서 HyDS3 시험 준비 사이트를 새로 만들어 줘. 자료는 (자료 폴더 이름)에 있어. 한 단계가 끝나면 멈추고, 그 단계의 '확인'을 하나씩 해 본 결과를 알려 줘. 모르는 건 짐작하지 말고 물어봐.

단계마다 화면을 `shots/`의 같은 이름 사진과 비교해 보고, "확인했어. 다음 단계 진행해 줘."라고 말하면 돼요.

## 들어 있는 것

| 폴더·파일 | 내용 |
|---|---|
| `CLAUDE.md` | 사내 클로드가 먼저 읽는 규칙 |
| `guide/` | 새 사이트 만드는 순서 0~4(폴더, 자료 정리와 MASTER 코드, 모의시험, 시험 대비, 점검) |
| `css/design.css` | 색·글자·간격 값과 모든 부품 |
| `js/design.js` | 모양에 필요한 동작만(화면 높이 맞춤, 보기 메뉴, 탭 손잡이, 메뉴, 코드 칸 색) |
| `pages/` | 화면별 예시 페이지 |
| `shots/` | 예시 페이지의 기준 사진 |
| `fonts/` | Pretendard(글), JetBrains Mono(코드). 둘 다 무료(OFL) |
| `LICENSES/` | 글꼴과 키트 코드의 라이선스 |
| `check.py` | 적용 뒤 점검: 키트 파일이 바뀌었는지, 새 인터넷 주소·새 색·따로 정한 글꼴이 생겼는지, 기록 저장 이름이 사라졌는지, 키트에 없는 이름을 썼는지 |

## 점검 도구

파이썬만 있으면 돼요(따로 설치할 것 없음).

```
python design-kit/check.py --baseline 새사이트폴더   (처음 한 번: 지금 상태를 적어 둬요)
python design-kit/check.py 새사이트폴더              (바꾼 뒤마다)
python design-kit/check.py --selftest                     (점검 도구가 잘 도는지)
```

## 화면 크기

- 맥북 14(1512×945)에 맞춰 만들었고, 다른 화면에서는 높이에 맞춰 통째로 커지거나 작아져요.
- 1920×1080 모니터에서는 설계 폭 1680으로 보여요.
