# 시험 준비 사이트 디자인 키트

회사 시험 준비 사이트를 어두운 애플 앱 느낌(검정 바탕, 파랑 한 가지, 미끄러지는 탭, 한 화면에 들어가는 배치)으로 바꾸는 키트예요.
사이트의 내용과 기능은 그대로 두고 모양만 바꿔요. 코드 찾기 탭만 일하는 방식도 바뀌어요.

예시 페이지의 내용(카페 판매 데이터, 코드)은 모두 지어낸 것이에요.

## 받는 법

1. 메일에 붙은 `design-kit-2026-11-09.zip`을 내려받아요.
2. 압축을 풀어요(윈도우: 파일을 오른쪽 단추로 눌러 '압축 풀기'). `design-kit` 폴더가 생겨요.
3. `design-kit/pages/index.html`을 브라우저로 열면 예시 화면을 볼 수 있어요.
   - 인터넷 없이 열려요.
   - 오른쪽 위 '보기'에서 어둡게·밝게와 글자 크기를 바꿀 수 있어요.

메일 검사에서 압축 파일이 막히면 확장자를 바꾸거나 암호를 걸지 말고 보안 담당에게 물어보세요.

## 사이트에 넣는 법

1. `design-kit` 폴더를 사이트 폴더 옆에 둬요.
2. 사내 클로드 코드에 이렇게 말해요.

   > design-kit/CLAUDE.md를 먼저 읽고, guide/00-prepare.md부터 한 단계씩 해 줘. 단계가 끝날 때마다 멈추고 확인한 것을 알려 줘.

3. 단계마다 화면을 기준 사진(`shots/`)과 비교하고, 문제를 하나 실행해 보고, 기록이 남는지 봐요.

사내 클로드는 사이트의 **복사본**에서 일해요(0단계). 원래 사이트는 마지막에 확인하고 나서 바꿔요.

## 들어 있는 것

| 폴더·파일 | 내용 |
|---|---|
| `CLAUDE.md` | 사내 클로드가 먼저 읽는 규칙 |
| `guide/` | 단계별 적용 안내 0~7 |
| `css/design.css` | 색·글자·간격 값과 모든 부품 |
| `js/design.js` | 모양에 필요한 동작만(화면 높이 맞춤, 보기 메뉴, 탭 손잡이, 메뉴, 코드 칸 색) |
| `pages/` | 화면별 예시 페이지 |
| `shots/` | 예시 페이지의 기준 사진 |
| `fonts/` | Pretendard 글꼴(무료, OFL) |
| `LICENSES/` | 글꼴과 키트 코드의 라이선스 |
| `check.py` | 적용 뒤 점검: 키트 파일이 바뀌었는지, 새 인터넷 주소·새 색이 생겼는지, 기록 저장 이름이 사라졌는지, 키트에 없는 이름을 썼는지 |

## 점검 도구

파이썬만 있으면 돼요(따로 설치할 것 없음).

```
python design-kit/check.py --baseline 사이트복사본폴더   (처음 한 번: 지금 상태를 적어 둬요)
python design-kit/check.py 사이트복사본폴더              (바꾼 뒤마다)
python design-kit/check.py --selftest                     (점검 도구가 잘 도는지)
```

## 화면 크기

- 맥북 14(1512×945)에 맞춰 만들었고, 다른 화면에서는 높이에 맞춰 통째로 커지거나 작아져요.
- 1920×1080 모니터에서는 설계 폭 1680으로 보여요.
