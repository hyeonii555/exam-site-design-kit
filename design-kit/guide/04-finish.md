# 4단계 · 마무리 점검

1. `python design-kit/check.py hyds3-site` → '문제' 줄이 없어야 한다(새 인터넷 주소, 키트에 없는 새 색, 키트에 없는 k- 이름, 바뀐 키트 파일).
2. **글꼴을 실제로 확인한다.** 브라우저에서 편집기의 코드 줄을 오른쪽 단추 → '검사' → 'Computed'(계산됨) 탭 맨 아래 'Rendered Fonts'(렌더링된 글꼴)를 본다.
   - 코드: `JetBrains Mono`(한글 주석은 `Pretendard Variable`)
   - 글: `Pretendard Variable`
   - `Consolas`, `Courier New`, `맑은 고딕`이 보이면 글꼴 파일 경로(`k/fonts/`)나 편집기 설정을 고친다.
   - 편집기, 결과 출력, 시험 대비 코드, 풀이 탭 코드 네 곳을 모두 본다.
3. 화면마다 기준 사진과 나란히 놓고 본다(어둡게 한 번, 밝게 한 번, 창 크기 1512×945 가까이).
4. 끝까지 한 번씩 해 본다.
   - 모의시험: 회차를 골라 세 소문항 풀기(맞는 답, 틀린 답, 오류) → 채점 → 새로 고침 뒤 기록 확인
   - 시험 대비: 기출 문제 붙여 넣기 → 오른쪽 MASTER 확인 → 전체 복사
5. 인터넷을 끈 상태로 다시 열어 본다(시험장 대비).
6. 다 맞으면 사람에게 알린다.

## 막혔을 때

| 보이는 것 | 볼 곳 |
|---|---|
| 글꼴이 안 바뀐다 | `k/css`와 `k/fonts`가 같은 `k` 폴더 아래에 있는지, check.py의 '글꼴을 따로 정한 곳'을 지웠는지, 편집기 설정에 fontFamily가 있는지 |
| 모양이 하나도 안 나온다 | 맨 바깥 `<div class="k-app" data-k-fit>`가 있는지, `<link>` 경로가 맞는지 |
| 손잡이가 엉뚱한 곳에 있다 | 지금 것에 `aria-current`·`aria-pressed`·`aria-selected`가 하나만 있는지 |
| 코드 색이 안 들어간다 | `<pre>`에 `data-k-hl`이 있는지. 그래도 안 되면 넣은 뒤 `kDesign.paint(부모)` |
| 칸이 화면 밖으로 넘친다 | 견본에서 지운 요소가 있는지. 견본의 구조로 되돌린다 |
| 파일로 열면 자료가 안 읽힌다 | fetch 대신 `data/*.js`(`window.ROUNDS = …`)를 `<script>`로 읽는다 |
