# 1단계 · 자료를 데이터 파일로 정리하기

화면은 건드리지 않는다. 회사 자료를 `data/` 아래 두 파일로 정리한다. 자료는 **빠짐없이** 쓴다.

## 자료

| 자료 | 쓰는 곳 |
|---|---|
| 기출 시험지 word(.docx): 2023년 1·2·3·4차, 2026년 1·2·3차 | 회차, 주제 글, 소문항 글 |
| 풀이 ipynb(일부 문제만) | 풀이 코드와 정답 출력 |
| 데이터 xlsx | 문제에서 읽는 데이터. `data/files/회차/` 아래에 이름 그대로 복사 |

## 읽는 법 (파이썬 표준 라이브러리로 된다)

- **docx:** 압축 파일이다. `zipfile`로 열어 `word/document.xml`을 읽고, `<w:p>` 문단마다 `<w:t>` 글자를 이어 붙이면 줄 글이 나온다. 표는 `<w:tbl>` 안의 칸을 ` | `로 이어 붙인다.
- **소문항 나누기:** 문단 첫머리의 번호로 자른다. 쓰이는 번호 모양을 먼저 모두 찾아 사람에게 보여 준다. (1) · 1) · ① · 1. · [문제 1] 등.
  - 첫 번호 앞의 글이 주제 글(데이터 설명)이다.
  - 큰 문제가 여럿이면 큰 문제마다 주제 글과 소문항이 따로 있다.
- **ipynb:** JSON이다. `cells` 중 `cell_type`이 `code`인 칸의 `source`가 코드, `outputs`의 `text` 또는 `data["text/plain"]`이 출력이다.
  - 어느 칸이 어느 소문항인지는 칸 앞의 마크다운이나 주석의 번호로 짝짓는다.
  - 짝이 애매하면 표로 정리해 사람에게 확인받는다.

## 파일 1: `data/rounds.json` (모의시험이 쓴다)

```json
[{ "id": "2023-1", "name": "2023년 1차", "minutes": 120,
   "problems": [{ "n": 1, "theme": "주제 글 전체", "files": ["files/2023-1/sales.xlsx"],
     "qs": [{ "n": "1", "text": "소문항 글",
              "solution": { "code": "풀이 코드", "from": "ipynb", "checked": true },
              "answer": "정답 출력(없으면 null)",
              "topics": ["two-sample-ttest"] }] }] }]
```

- `from`: ipynb에서 가져왔으면 `"ipynb"`, 새로 만들었으면 `"made"`.
- 시험 시간(`minutes`)을 모르면 `null`로 두고 사람에게 묻는다.

## 풀이가 없는 소문항

1. 사내 클로드가 풀이를 만든다(`from: "made"`).
2. 그 문제의 xlsx로 실제로 돌려 본다. PC의 파이썬으로 돌린다(`pandas`, `openpyxl`).
3. 오류 없이 돌고 결과가 문제의 요구(자리수, 형식)에 맞으면 `checked: true`, 아니면 `false`.
4. 만든 풀이의 출력은 `answer`에 넣지 않는다. 정답이 확실하지 않으니 모의시험에서는 직접 표시로 채점한다.

## 파일 2: `data/topics.json` (시험 대비가 쓴다)

소문항마다 `topics`(작업 유형)를 붙였으면, 유형마다 하나로 모은다.

```json
[{ "id": "two-sample-ttest", "name": "두 집단 평균 비교",
   "words": ["t-검정", "t검정", "평균이 다른지", "두 집단"],
   "imp": ["from scipy import stats"],
   "master": "MASTER 코드(아래 규칙)",
   "uses": [{ "q": "2023-1 문제2 (3)", "code": "그 풀이 코드 그대로", "from": "ipynb", "checked": true }] }]
```

- **유형 나누기:** 먼저 전체 소문항을 보고 유형 목록을 만들어 사람에게 확인받는다. 결측치 채우기, 그룹별 집계, 두 집단 t-검정, 카이제곱, 상관, 회귀, 분류 모델, 군집 같은 단위다. 소문항 하나가 여러 유형일 수 있다.
- `words`: 시험지에서 이 유형을 알아볼 낱말들. 실제 소문항 글에서 뽑는다.
- `uses`: 이 유형이 쓰인 **모든** 풀이 코드다. 하나도 빼지 않는다.

## MASTER 코드 만드는 규칙

한 유형의 `uses` 코드를 **전부** 합쳐 하나로 정리한 코드다.

1. 맨 위 주석에 합친 출처를 모두 적는다: `# 2023-1 (3) · 2023-4 (2) · 2026-2 (5)를 합침`
2. 겹치는 줄은 한 번만 쓴다. 변수 이름은 가장 흔한 것으로 맞춘다.
3. 방식이 다른 갈래(옵션, 다른 함수)는 지우지 않고, 바로 아래에 주석 줄로 남긴다. 줄 끝에 언제 쓰는지와 출처를 단다.

   ```python
   t, p = stats.ttest_ind(a, b)                        # 기본 (2023-1 (3))
   # t, p = stats.ttest_ind(a, b, equal_var=False)   # 분산이 다를 때 (2026-2 (5))
   ```

4. 주석을 뺀 기본 길은 그대로 돌아가야 한다. 그 유형이 나온 기출 xlsx 하나로 돌려 보고 확인한다.
5. 열 이름처럼 문제마다 바뀌는 곳은 가장 흔한 기출의 이름을 쓰고, 줄 끝에 `# ← 열 이름 바꾸기`를 단다.
