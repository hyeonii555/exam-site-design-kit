# 0단계 · 준비: 복사본 만들기, 지금 상태 적어 두기

이 단계에서는 사이트를 바꾸지 않는다.

## 할 일

1. 사이트 폴더를 통째로 복사해 복사본을 만든다. 예: `site` → `site-design`.
   - 이후 모든 작업은 `site-design`에서만 한다.
   - 원래 `site`는 마지막 단계(7단계)까지 건드리지 않는다.
2. 복사본을 원래 방법대로 열어 본다.
   - 화면이 원래처럼 나오는지 본다.
   - 기출 문제 하나를 실행해서 결과가 나오는지 본다.
3. 지금 상태를 적어 둔다:

   ```
   python design-kit/check.py --baseline site-design
   ```

   - `site-design/.k-check.json` 파일이 생긴다.
   - 이 파일에는 지금 있는 인터넷 주소, 색 값, 기록 저장 이름(localStorage 키)이 적힌다. 나중에 새로 생긴 것만 알려 준다.
4. 화면에 나온 '기록 저장 이름' 목록을 사람에게 보여 준다. 이 이름들은 끝까지 바꾸면 안 된다.
5. 사이트가 어떤 화면들로 되어 있는지 적는다. 예: 탭 넷의 이름과 파일, 문제 풀이 화면, 채점 결과 화면.
   - 키트 예시 페이지(`pages/index.html`)와 짝을 지어 적는다.

## 사이트가 리액트·뷰 같은 도구로 되어 있으면

- HTML의 `class`를 그 도구의 방식으로 쓴다. 리액트는 `className`.
- 이벤트·상태 코드는 그대로 두고, 그려지는 요소의 class와 감싸는 요소만 바꾼다.
- 그 도구가 화면을 다시 그린 뒤에도 손잡이가 맞게, 고른 탭에는 aria 값을 쓴다(CLAUDE.md '이름 붙이는 법').

## 확인

- [ ] `site-design`이 원래처럼 열리고, 문제가 실행된다
- [ ] `site-design/.k-check.json`이 생겼다
- [ ] 기록 저장 이름 목록을 사람에게 보여 줬다
- [ ] 화면과 예시 페이지의 짝을 적었다
