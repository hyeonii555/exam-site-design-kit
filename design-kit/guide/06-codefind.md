# 6단계 · 코드 찾기 탭 (모양과 일하는 방식)

이 탭은 사람(사용자)과 정한 대로 **일하는 방식도 바뀐다.** 예전에는 관련도 순 카드에서 고르게 했다면, 이제는 시험 문제를 붙여 넣으면 소문항마다 가장 맞는 코드를 채운 초안 하나를 보여 준다.

베낄 곳: `pages/codefind.html`과 `pages/codefind-demo.js`(동작 예시). 기준 사진: `shots/codefind-*.jpg`.

## 화면이 하는 일

- **처음 화면:** 시험 문제를 붙여 넣는 칸 하나. 그 아래는 결과가 놓일 빈 틀이다. 탭을 열면 칸에 커서가 있다.
- **붙여 넣으면 바로:**
  - 주제 글과 소문항으로 나눈다.
  - 소문항마다 코드를 찾아 줄마다 보여 준다(소문항 | 고른 코드).
  - 맨 위 줄은 주제 글과 준비 코드(import + 데이터 읽기)다.
- **오른쪽 칸:** 고른 소문항의 후보 코드가 모두(최대 3개) 보인다. 누르거나 1·2·3 키로 바꾼다. 위·아래 키로 소문항을 옮긴다.
- **위쪽 문제 탭:** 문제마다 탭이 생긴다. 시험 하나에 주제 문제가 4개 넘게 나온다. 끝의 '새 문제'를 누르면 붙여 넣는 칸이 다시 나온다.
- **전체 복사:** 준비 코드 다음에 소문항마다 `# (n) 소문항 글` 주석과 코드를 이어 붙여 복사한다.
- **글 고치기:** 소문항이 잘못 나뉘었을 때 그 자리에서 고친다. 다시 찾기는 바뀐 소문항만 새로 찾는다.

## 할 일

1. 회사 사이트에서 지금 코드 찾기 탭의 **찾는 함수**를 찾는다.
   - 글을 받아 관련도 순 코드 목록을 돌려주는 함수다.
   - 그 함수 이름, 받는 것, 돌려주는 것을 적고 사람에게 보여 준다.
   - 이 함수는 지우지 않는다.
2. `pages/codefind-demo.js`를 사이트 복사본의 `k/js/codefind.js`로 복사한다.
3. 복사한 파일에서 아래 세 곳만 바꾼다.
   - **(1) 가짜 자료를 지운다:** `var FAKE = …;` 부분, `POOL`, `wordScore`, 그리고 `#result` 와 `#edit` 로 가짜 문제를 넣는 부분.
   - **(2) `findCodes(subText, themeText)` 안을 회사 사이트의 찾는 함수로 바꾼다.** 돌려주는 모양은 꼭 이렇게 맞춘다.

     ```js
     [{ src: '기출 풀이 · 3회 (4)', kind: 'past', imp: ['from scipy import stats'], code: 'rain = ...\nprint(round(p, 4))' }, …]   // 최대 3개
     ```

     | 이름 | 넣는 것 |
     |---|---|
     | `kind` | 기출 풀이면 `'past'`, 개념 자료면 `'note'`, 기출을 풀어 만든 코드면 `'made'` |
     | `src` | 출처를 사람이 읽는 글로: '기출 풀이 · 회차 (번호)', '개념 자료 · 자료 이름', '만든 풀이 · 확인 전' |
     | `imp` | 그 코드에 필요한 import 줄들 |
     | `code` | import 줄을 뺀 나머지 코드 |

     - 회사 검색이 코드 한 덩어리만 준다면, 코드 줄 중 `import`나 `from`으로 시작하는 줄을 `imp`로 옮기고 나머지를 `code`로 둔다.
     - 찾을 글은 `subText + ' ' + (주제 글의 핵심 낱말)`로 넣으면 더 잘 맞는다.
     - 순서는 관련도 순으로 둔다. 비슷하면 past, note, made 순이다.
   - **(3) '비슷한 기출':** 회사 사이트가 주제 글로 비슷한 기출을 찾을 수 있으면 `makeProblem`의 `similar`에 `{ label: '3회 편의점 판매 데이터' }`를 넣는다. 못 찾으면 `null` 그대로 둔다(줄이 안 나온다).
4. 코드 찾기 탭의 원래 결과 화면(카드 목록) HTML을 지우고, 그 자리에 이것만 둔다.

   ```html
   <div id="cf" style="display: contents"></div>
   <script src="k/js/codefind.js"></script>
   ```

   - `#cf`는 `k-main` 바로 안에 둔다. 머리줄과 탭은 2단계 그대로다.
   - 원래 찾는 함수가 들어 있는 `<script>`는 지우지 않는다. `codefind.js`보다 **앞에** 둔다.
5. 소문항 번호 모양이 (1)이 아닌 사이트라면(1), ①, 1. 등), `MARK` 한 줄만 바꾼다.
   - 예: `①`이면 `/([①-⑳])/g`. 이때 번호 글자를 숫자로 바꾸는 줄도 필요하니 사람에게 묻는다.

## 하지 않는 것

- 관련도 점수나 순위 숫자를 화면에 보이지 않는다.
- 카드에서 주제를 골라야만 코드가 보이게 하지 않는다(사용자가 번거롭다고 했다).
- 붙여 넣은 문제를 저장하지 않는다(새 기록 저장 이름이 생긴다). 탭은 화면을 닫으면 사라져도 된다.
